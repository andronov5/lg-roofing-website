# LG Roofing website concept

A static, responsive website concept for LG Roofing, LLC in the Denver area. It is built with plain HTML, CSS, and JavaScript and is ready for GitHub Pages after the business approves the content.

## Run locally

Open `index.html` directly, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## What works

- Responsive desktop and mobile navigation
- Service shortcuts that preselect the estimate form
- FAQ accordion
- Estimate form that prepares an SMS to `(720) 435-4421`
- Copy-to-clipboard fallback for desktop visitors
- Accessible labels, keyboard states, reduced-motion support, and semantic page structure
- `noindex` protection while the concept is awaiting business approval

## Verification required before production

This concept uses public information from the company’s BBB profile. Before publishing it as an official LG Roofing website, confirm with the owner:

- Exact legal/business name and preferred logo
- Current phone number, address, hours, and service area
- Residential and commercial service availability
- Licensing, insurance, warranties, financing, and emergency availability
- Whether the business wants a hosted form, email delivery, or SMS workflow
- Permission to publish real project photos, reviews, and customer names

Do not describe LG Roofing as BBB accredited. Its public BBB profile currently shows an A+ rating but says the business is not accredited.
